# tnt-docs

Раздел документации для Tarantool: каталоги файлов markdown становятся
сайтом прямо на узле — меню разделов с планом ненаписанных страниц, поиск
по-русски в окне ⌘K, светлая и тёмная тема, подсветка кода — внутри рамки
сайта приложения. Правка документа видна без сборки и без перезапуска.

```lua
local docs = require('tnt.docs')
local server = require('http.server')

local httpd = server.new('127.0.0.1', 8088, { log_requests = false, idle_timeout = 60 })

docs.new({
    directory = 'docs',
    groups = { { title = 'Начало', pages = { 'install', 'usage' } } },
    hidden = { 'drafts' },
}).attach(httpd)

httpd:start()
```

Зависимости: [tnt-markdown](https://github.com/tnt-skein/tnt-markdown),
[tnt-router](https://github.com/tnt-skein/tnt-router),
[tnt-template](https://github.com/tnt-skein/tnt-template),
[tnt-morphology](https://github.com/tnt-skein/tnt-morphology),
[tnt-fs](https://github.com/tnt-skein/tnt-fs),
[tnt-log](https://github.com/tnt-skein/tnt-log),
[tnt-clock](https://github.com/tnt-skein/tnt-clock),
[tnt-context](https://github.com/tnt-skein/tnt-context),
[tnt-must](https://github.com/tnt-skein/tnt-must),
[tnt-external](https://github.com/tnt-skein/tnt-external) и рок `http`.

## Зачем

Документацию пишут markdown рядом с кодом, а читают браузером. Между
этими концами — работа, которую каждый раздел документации делает
одинаково, и пакет делает её одним вызовом:

- **Меню — от приложения.** Разделы меню и порядок страниц задаёт
  приложение — файлом меню, группами или тем и другим; пакет рисует
  колонку-гармошку, «назад» и «вперёд» и главную с карточками страниц.
- **План виден читателю.** Пункт меню без страницы открывается заглушкой
  «скоро», а сводная страница показывает весь план одной таблицей.
- **Своды.** Руководство приложения и документы пакетов из соседнего
  репозитория — один раздел, со ссылками между ними.
- **Поиск по-русски.** Указатель по разделам страниц, слово сводится
  к основе: «шаблоны» находит «шаблон». Окно ⌘K отвечает по мере набора,
  страница выдачи работает без сценариев.
- **Рамка сайта — настройками.** Марка, пункты шапки, ссылки наружу
  и подвал приходят от приложения; раздел подключается и к своему
  серверу, и к роутеру приложения.
- **Вид едет роком.** Стили, сценарии, значки и шрифты собраны заранее
  и раздаются из памяти узла с меткой версии в адресе.
- **Безопасно по умолчанию.** Разметка экранирует всё из документа,
  ответы несут Content-Security-Policy без встроенных сценариев и стилей,
  ссылка на скрытый документ остаётся текстом.

## Установка

```sh
tt rocks install tnt-docs --server=https://tnt-skein.github.io/rocks
```

Или из исходников:

```sh
git clone https://github.com/tnt-skein/tnt-docs.git
cd tnt-docs && tt rocks make --server=https://tnt-skein.github.io/rocks
```

## Как пользоваться

| Настройка | Умолчание | Что делает |
|---|---|---|
| `directory` | — | каталог разметки: страница — файл `<имя>.md` |
| `roots` | — | своды `{ section, directory, hidden }`: адреса `<начало>/<свод>/<имя>` |
| `prefix` | `/docs` | начало адресов раздела |
| `title` | `Документация` | название раздела |
| `start` | нет | куда ведёт начало раздела; нет — главная с карточками |
| `menu` | нет | файл меню: разделы, страницы, состояние `{позже}`, `{частично}` |
| `groups` | нет | группы по порядку: `{ title, section, pages }` |
| `rest` | `Прочее` | группа для страниц вне меню и групп |
| `hidden` | нет | документы каталога, которых на сайте нет |
| `plan` | нет | сводная страница `page` и план страниц `pages` |
| `suggestions` | нет | подсказки пустого окна поиска |
| `card` | нет | карточка пакета по имени страницы и своду |
| `frame` | марка — `title` | рамка сайта: марка, шапка, ссылки, подвал |
| `recheck` | `1` | сколько секунд разобранное не сверяется с диском |
| `warm` | `true` | прогревать ли раздел в фоне при подключении |
| `views` | шаблоны пакета | свой каталог шаблонов страниц |

| Адрес | Что отвечает |
|---|---|
| `/docs` | начальная страница либо главная |
| `/docs?q=шаблоны` | страница выдачи поиска |
| `/docs/search.html?q=…`, `/docs/search.json?q=…` | ответ окна поиска и выдача JSON |
| `/docs/<план>` | сводная страница плана |
| `/docs/[<свод>/]<имя>` | страница документа либо заглушка «скоро» |
| `/docs/[<свод>/]<имя>/source` | разметка документа простым текстом |
| `/docs/assets/<метка>/<файл>` | вид раздела с годовым сроком жизни |

Приложению со своим роутером — подключение участком адресов:

```lua
docs.new({ roots = roots, menu = 'resources/docs/menu.md', frame = frame }).mount(router)
```

Узлу без своего приложения — роль со своим портом:

```yaml
roles: [tnt.docs.role]
roles_cfg:
  tnt.docs.role:
    listen: 127.0.0.1:8088
    directory: docs
    hidden: [drafts]
    options: app.docs     # модуль с настройками-функциями: card
```

Отказ — страницей на рамке раздела: 404 — «Такой страницы нет», 500 —
номер происшествия, подробности — в журнал узла.

## Проверки

```sh
make deps          # luatest, luacheck, luacov с cluacov и зависимости пакета в .rocks
make check         # форматирование, линт, проверки, покрытие с порогом 100 %
make mutants-all   # мутационное тестирование утилитой tnt-mutants из PATH, порог 100 % убитых
```

Покрытие строк — 100 %, убитых мутантов — 100 % (178 проверок, 832 мутанта
в пятнадцати модулях). Каждый пример документа исполняется проверкой
`test/examples_test.lua`.

Вид собирается из `ui/` (`bun install && bun run build`) и сразу
пакуется в модуль `tnt/docs/public/bundle.lua`; для установки пакета
bun не нужен.
